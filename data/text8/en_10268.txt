Improvements to the Controls for CCRP Bombing!
20 October 2026
Development
<>CCRP Bombing, now simple and easy to understand!
<>In the upcoming major update, we’ve reworked the controls for CCRP (Constantly Computed Release Point) bombing. The previous mechanic was sufficient when CCRP was a niche tool used by only the most experienced pilots. However with the introduction of Nuclear Escalation, using the automated system to drop nuclear bombs, CCRP has become the primary method for delivering a nuclear strike. The old interface however does have some drawbacks. We’ve redesigned the system so that it no longer interferes with standard bomb dropping or clutters half the screen.
<>What were the current drawbacks? The bomb-release button was used for both CCRP and manual release, causing the two functions to conflict. Once CCRP bombing mode was enabled, it was no longer possible to drop a bomb manually. This is a big problem when dealing with nuclear weapons in Nuclear Escalation. Plus, the option to arm the release mechanism at the start of a run would completely break manual release if a target point had been set using the optical sight. Players would only discover this at the worst possible moment, right when they needed to drop their payload. Lastly, the on-screen indicators took up too much space, and the requirement to hold down the release button proved highly inconvenient.
<>The new version addresses all of these issues. It requires no dedicated button, does not conflict with the standard release function, and uses a simple, uncluttered display. The auto-release indicator is now positioned within the battlefield view in a way that does not obstruct visibility. Manual bomb release is now possible, even when a point of interest is active. We aimed to ensure the mechanic works predictably, eliminating any guesswork regarding why a bomb might fail to release from a pylon. CCRP bombing is now more convenient across level flight, dives, and pull-up maneuvers. In the latter case (toss bombing), the indicator sticks to the bottom of the screen, allowing for continued monitoring of timing and heading.
<>For those just learning the ropes of CCRP bombing, here’s a quick refresher on how it works. CCRP allows you to drop bombs on a pre-designated point on the ground, even if you cannot see it directly. By designating a target (using the “Activate Point of Interest” button, default key: Alt + Middle Mouse Button or MMB click on a minimap), a red targeting box appears on the ground at that location. Activate the automatic release icon (found in the quick-action panel) or assign a dedicated keybind in the control settings menu. A vertical directional arrow appears in the target point, complete with the required heading, the deviation of the current heading from the set value, and an indication of the time remaining until target. Once the automatic release indicator aligns with the crosshairs of the bombsight, the system will automatically release the bomb at the right moment. If the deviation from the course is significant, the release will not occur; the indicator will remain gray and will display the current course deviation. You can use the weapon selector (Caps Lock or Left Shift + S) to choose which bombs to drop and in what quantity, whether a single bomb, a pair, or a salvo (the quantity selector is bound to Left Shift + B by default).
